### Getting Started

To run and build this project locally, you will need the Unity Game Engine installed.

#### Prerequisites

  * **Unity:** You will need the specific version of the Unity Editor used for this project (the version is typically found in the `ProjectSettings` folder files).
  * **Development Environment:** A code editor that supports C\#, such as [Visual Studio Community](https://visualstudio.microsoft.com/vs/community/) or [Visual Studio Code](https://code.visualstudio.com/).

#### Installation and Setup

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/LokeshPatnaik1999/The-Hungry-Crab.git
    ```
2.  **Open in Unity:**
      * Launch the Unity Hub.
      * Click "Add" and navigate to the root directory of the cloned project (`The-Hungry-Crab`).
      * Open the project with the correct Unity Editor version. Unity will import all the assets and files.
3.  **Run:**
      * Once the project is open, navigate to the main scene (usually in the `Assets` folder) and press the **Play** button in the Unity Editor to run the game.
